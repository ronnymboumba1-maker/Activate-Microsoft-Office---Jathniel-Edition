Version 3.0.0 - JATHNIEL EDITION

---

📖 PRÉSENTATION GÉNÉRALE

J4 Activator est un outil d'activation KMS complet et interactif pour l'écosystème Microsoft. Il permet d'activer Microsoft Office, Windows, Visio et Project en quelques clics, grâce à une interface intuitive et des serveurs KMS publics.

Conçu pour être simple d'utilisation, il détecte automatiquement les versions installées et propose un menu clair pour sélectionner ce que vous souhaitez activer.

---

✨ FONCTIONNALITÉS PRINCIPALES

Fonctionnalité Description
Activation Office Support Office 2016, 2019, 2021, 2024
Activation Windows Support Windows 10/11 Pro, Enterprise, Education
Activation Visio Support Visio 2016, 2019, 2021, 2024
Activation Project Support Project 2016, 2019, 2021, 2024
Détection automatique Détecte les versions installées
Menu interactif Navigation simple par numéros
Serveurs KMS 15+ serveurs publics, sélection automatique
Mode silencieux Activation sans affichage
Logging Génération de logs pour le débogage
Rollback Rollback Office vers version stable
Désactivation mises à jour Bloque les mises à jour Office
Auto-installation Installe les dépendances automatiquement
